# 道具 Icon 来源说明

本目录图标来自 [Game-icons.net](https://game-icons.net/)，采用 **CC BY 3.0** 协议。

使用这些图标时，需要在游戏内或 README 中注明来源，例如：

> Icons by Lorc / Delapouite. Available on https://game-icons.net

`Assets/Resources/Icons/` 中为运行时加载副本（内容相同）。
