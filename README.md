# MHWorld_Unity

怪物猎人 2G 气质的 Unity 挂机原型：日常挂机 + 主动出击 + 三层熟练度。  
目标平台：**微信小游戏**（标准设备 **iPhone 12**，竖屏 390×844）。

## 试玩

1. Unity **2022.3** 打开工程  
2. 打开 `Assets/Scenes/SampleScene.unity`  
3. Game 视图设为 **390×844**（或 iPhone 12）后点击 **Play**

## 当前结构

| 页 | 内容 |
|----|------|
| 角色 | **点选流派**、装备、出征背包、挂机小怪、出击大怪（含胜率） |
| 熟练 | 上：同心圆环（环上显示等级）／下：专精·武种·心法进度 + 招式 + 地图 |
| 仓库 | 素材与已拥有武器、出征背包装配 |
| 制造 | 道具店 / 武器防具工房（11 武器种、多套防具） |
| 战斗弹窗 | 主动讨伐独立窗口 |

### 熟练度命名

| 名称 | 含义 | 原技术叫法 |
|------|------|------------|
| **专精** | 当前具体武器 | 外圈 |
| **武种** | 同种武器共享 | 内圈 |
| **心法** | 风格组共享 | 内内圈 |

圆环转满一圈升一级，环上数字即为当前等级。

详见 `游戏设计.md`。
