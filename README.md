# MHWorld_Unity

怪物猎人主题的 Unity 挂机原型。

## 试玩

1. Unity **2022.3.19f1** 打开工程  
2. 打开 `Assets/Scenes/SampleScene.unity`  
3. 点击 **Play**（会自动启动挂机 UI）

## 当前内容

- 挂机战斗 / 猎人等级 / 大剑熟练度  
- 武器与防具工房  
- 离线结算与本地存档  
- 道具 / 装备 icon（背包、工房、狩猎页）
