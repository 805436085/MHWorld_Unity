# MHWorld_Unity

怪物猎人 2G 气质的 Unity 挂机原型：日常挂机 + 主动出击 + 三圈熟练度。

## 试玩

1. Unity **2022.3** 打开工程  
2. 打开 `Assets/Scenes/SampleScene.unity`  
3. 点击 **Play**

## 当前结构

| 页 | 内容 |
|----|------|
| 角色 | 装备、出征背包、挂机小怪、出击大怪（含胜率） |
| 熟练度 | 外圈/内圈/内内圈同心圆 + 招式 + 地图熟练 |
| 仓库 | 素材与已拥有武器 |
| 制造 | 武器/防具工房 |
| 战斗弹窗 | 主动讨伐独立窗口 |

详见 `游戏设计.md`。
